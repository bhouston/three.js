Tiny neural appearance fixture for the Three.js examples.

This file is generated for runtime testing of the Three.js neural appearance
loader and material. It does not contain a trained NVIDIA checkpoint.

The converter at utils/neural-appearance/convert_checkpoint.py targets
checkpoints produced by:

  https://github.com/NVlabs/neuralappearance

That repository is licensed under the Apache License 2.0. Its bundled
FauxLeather MaterialX source can be trained on compatible NVIDIA hardware and
converted into the same runtime format as this fixture.
