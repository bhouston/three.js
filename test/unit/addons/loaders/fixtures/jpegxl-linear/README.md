# Linear HDR JPEG XL fixtures

Generated by Ben Houston's agent task for these tests; dedicated to the public domain under CC0-1.0.

Both files are losslessly encoded 2 × 2 RGB, 32-bit floating-point images using linear sRGB/BT.709 primaries and D65, with no alpha channel. The top row is `(0, 0.5, 1)`, `(2, 4, 8)`; the bottom row is `(1, 1, 1)`, `(0.25, 0.5, 0.75)`.

Encoded with libjxl 0.12.0 `cjxl`, lossless mode, from a floating-point PFM image. `linear-hdr-1000.jxl` uses an intensity target of 1000 nits; `linear-hdr.jxl` uses the default. The expected texture samples are identical: luminance metadata must not rescale material values.

The native decoder tests skip when float16 linear Canvas2D and `globalHDRHeadroom` are unavailable. They additionally require native JPEG XL decoding. They verify these fixtures through the actual `JXLLoader` and `GLTFLoader` material path without mocking decoding.
