# Hierarchical stratification experiment

Source of inspiration: Ahmed and Wonka, *Screen-Space Blue-Noise Diffusion of Monte Carlo Sampling Error via Hierarchical Ordering of Pixels* (2020), https://abdallagafar.com/publications/zsampler/. This experiment borrows the idea of hierarchical spatial ordering; it does not reproduce that paper's optimized ordering or claim its quality guarantees.

Each aligned 2×2 spatial block receives a randomly permuted quartet of leading base-four sample digits. Larger blocks assign subsequent digits using independent seeded square symmetries. A static hashed tail fills unused digits. Each frame digitally shifts this spatial rank with a base-two van der Corput sequence. Work is O(size² log(size) + size² depth), with O(size²) temporary storage beyond the returned volume. There is no iterative optimization, Fourier transform, dependency, or GPU requirement. Values are exact 24-bit fractions stored as Float32, in z,y,x order.

The intended strengths are cheap construction, local spatial stratification, and temporal prefix convergence: at each pixel a power-of-two frame prefix visits each corresponding value stratum exactly once. Leading spatial strata persist after the temporal XOR. For even sizes each 2×2 block occupies all four value quartiles in every frame. Seed changes the hierarchy, so runs remain deterministic. Odd sizes crop boundary blocks and weaken their balance.

The deliberate tradeoff is structured dyadic spectra and strong cross-pixel temporal correlation. This is scrambled ordered dithering, not an isotropic blue-noise optimizer. A shared temporal digital shift may leave spatial patterns visible under motion or nonlinear filtering. Frame 32 wraps to a different stratum but finite-depth texture wrapping creates a sequence discontinuity. Arbitrary non-power-of-two frame windows have weaker discrepancy guarantees. Prefix guarantees apply to scalar uniform samples, not all Monte Carlo integrands. Spatial blur and temporal reconstruction measurements must decide whether those compromises are acceptable for the actual use case.
