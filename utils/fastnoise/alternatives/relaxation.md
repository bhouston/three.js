# Alternating high-pass projections

`relaxation.js` starts from seeded white noise and alternates two inexpensive projections: subtract a separable spatial Gaussian approximation independently within every frame, then subtract a temporal Gaussian approximation independently at every pixel. Each projection restores an approximately uniform marginal distribution using an 8192-bin interpolated histogram CDF. Eight iterations are the default. All axes wrap periodically.

The motivation is the low-frequency error suppression in [Blue-noise Dithered Sampling](https://www.iliyan.com/publications/DitheredSampling/) and the separate spatial and temporal objectives of [Spatiotemporal Blue Noise Masks](https://research.nvidia.com/publication/2022-07_spatiotemporal-blue-noise-masks). This is an experimental alternating spectral-shaping heuristic, **not an implementation of either paper**, FAST, or void-and-cluster. Separate projections are intentional: isotropic 3D high-pass filtering alone does not guarantee blue spatial slices.

For `N = size * size * depth` and `K = iterations`, cost is O(K N), with three Float32 volumes (12N bytes) plus small histograms. No GPU, dependencies, sorting, energy table, pair search, or offline input texture is needed. `generate({ size, depth, seed, iterations })` returns deterministic Float32 values in z,y,x order in [0,1). Zero iterations returns seeded white noise and is useful as a control.

On this runner, a cold Node invocation produced the default 128×128×32 volume in approximately **131 ms**. Determinism and finite [0,1) range passed direct Node checks. This number is a single CPU generation measurement, not a renderer performance measurement or a comparison against FAST. The parent experiment's common benchmark should supply repeated timings and quality metrics. The existing Python comparison initially could not run in this worktree because the default Python environment lacks NumPy.

Limitations: histogram uniformity is approximate and global, rather than an exact per-pixel temporal permutation. Repeated high-pass steps can concentrate energy near Nyquist and produce directional or alternating patterns. Nonlinear histogram restoration can reintroduce low frequencies and does not preserve blue noise under every threshold or nonlinear integrand. Temporal averaging of complete cycles is not guaranteed to cancel exactly. The projection uses a symmetric five-tap Gaussian approximation rather than optimizing the actual causal EMA or a chosen renderer's reconstruction kernel. Consequently speed alone does not establish equivalent STBN/FAST quality; spatial/temporal spectra, blur error, EMA error and threshold tests must be assessed together.
